# Framework Docs

Framework-level docs live here instead of inside Family Tech product `memories/`.
The live runtime authority is still `scripts/smike/RUNTIME_ORCHESTRATOR.md` plus the current CLI/schema behavior.

## Taxonomy

- `docs/reference/` is for live authoritative framework reference.
- `docs/guides/` is for operator guides and generated walkthroughs.
- `docs/design/` is for historical plans, retrospectives, and redesign notes.
- `docs/acceptance/` is for acceptance packages and run artifacts.
- `docs/feedback/` is for temporary workflow feedback triage notes.
